## Overall Summary

This project implements **Prim's Algorithm for finding the Minimum Spanning Tree (MST) of a weighted graph in Python**. The objective is to connect all the vertices of the graph with the minimum possible total edge weight without forming any cycles.

The algorithm starts from a selected vertex and repeatedly chooses the **minimum-weight edge** that connects a selected vertex to an unselected vertex. The selected edges are added to the Minimum Spanning Tree until all vertices are connected.

The implementation demonstrates the practical application of Prim's Algorithm for solving **Minimum Spanning Tree problems**, with a time complexity of **O(V²)** for the given adjacency matrix implementation and a space complexity of **O(V)**.

## Overall Conclusion

The Minimum Spanning Tree problem was successfully implemented using **Prim's Algorithm in Python**. The algorithm efficiently selects the minimum-weight edges and connects all vertices while maintaining the minimum possible total cost.

This implementation provides a clear understanding of how Prim's Algorithm works and how it can be used to find an optimal network structure with minimum cost. It is commonly used in applications such as **network design, road connections, electrical grids, and communication systems**.
