## Overall Summary

This program implements a factorial program in Python using two approaches: **iterative** and **recursive** methods. Both methods calculate the factorial correctly, and their execution time is measured to compare their performance.

The iterative method uses a loop, while the recursive method uses repeated function calls. Both methods have **O(n) time complexity**, but they differ in space usage. The iterative method requires **O(1) space**, whereas the recursive method requires **O(n) space** due to the recursive call stack.

## Overall Conclusion

Both iterative and recursive methods are effective for calculating factorials. However, the **iterative method is generally more efficient in terms of memory usage** and is more suitable for larger inputs in Python.

The recursive method is useful for understanding the concept of recursion and how a problem can be solved by breaking it into smaller subproblems. Runtime measurements may vary depending on the system and execution environment.

Overall, this project demonstrates the importance of comparing algorithms based on **implementation, runtime, time complexity, and space complexity**.
