## Overall Summary

This project implements **Graph Traversal using Breadth-First Search (BFS) and Depth-First Search (DFS) in Python**. The objective is to traverse all the vertices of a graph starting from a given vertex.

The BFS algorithm uses a **queue** to visit nodes level by level, while the DFS algorithm uses **recursion** to explore nodes deeply before backtracking. Both implementations use a visited set to avoid visiting the same node multiple times.

The implementation demonstrates the practical application of graph traversal algorithms, with a time complexity of **O(V + E)** and a space complexity of **O(V)**.

## Overall Conclusion

The Graph Traversal problem was successfully implemented using **BFS and DFS approaches in Python**. Both algorithms efficiently traverse the given graph while ensuring that each reachable vertex is visited only once.

This implementation provides a clear understanding of how BFS and DFS work and highlights the difference between level-wise and depth-wise graph traversal. These algorithms form an important foundation for solving various graph-based problems in **Data Structures and Algorithms**.
